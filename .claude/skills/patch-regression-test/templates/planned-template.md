## 10. マージの判断基準（ガイドライン「8.4：マージの判断基準」）

- [ ] 確認範囲が確定している（ソースコードの修正だけの場合は、テストの対象にする修正箇所が確定している）
- [ ] 全確認範囲で共通のテストと確認範囲別の追加テストのうち対象のものが、すべて合格している（選択的に外した項目を除く。暫定合格は使わない）
- [ ] 判断待ちの項目が残っていない
- [ ] 想定どおりの差分は、すべてリーダーが承認している
- [ ] 選択的に外したテストレベルは、理由とともに残存リスクとして記録されている
- [ ] 対話なしで実行した場合は、要確認項目に担当者が対応している

## 11. 承認

承認は、このレポートには記入しない。開発チームのリーダーが PR を承認した後、スキルの承認の記録（`approve <PR 番号>`）で、Issue のコメントとして記録する。性能の結果も、そこに記録する。
